Configurar APIs de forma segura

El panel no guarda tokens ni API keys. Las claves entran por GitHub Secrets/Vercel Environment y el backend las usa sin exponerlas al navegador.

Cargando estado del backend...
  • Para que Sync funcione sin pedir token: configura GITHUB_ACTIONS_TOKEN en Vercel con permisos de workflow/repo.
  • Para mas fuentes: configura RAPIDAPI_KEY, ADZUNA_APP_ID, ADZUNA_APP_KEY, JOOBLE_API_KEY y los tokens ATS opcionales.
  • Para correr el scraper en GitHub Actions, duplica esas mismas claves como GitHub Secrets.
