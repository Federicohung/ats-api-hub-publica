Configurar APIs y ATS

Las claves no se guardan en este panel. Van como GitHub Secrets para que el scraper corra seguro en GitHub Actions.

  • RAPIDAPI_KEY para JSearch, que puede traer resultados indirectos tipo LinkedIn/Indeed/Google Jobs.
  • ADZUNA_APP_ID y ADZUNA_APP_KEY para Adzuna.
  • JOOBLE_API_KEY para Jooble.
  • ATS opcionales: GREENHOUSE_BOARDS, LEVER_SITES, ASHBY_BOARDS, SMARTRECRUITERS_API_KEY, WORKABLE_API_KEY, TEAMTAILOR_API_KEY, BREEZY_API_KEY.
  • Variables de enfoque: SPANISH_SEARCH_QUERIES, SPANISH_JOB_QUERIES, LATAM_SPAIN_LOCATIONS.
